# 005: detect-secrets runs without a baseline file

**Status**: accepted
**Date**: 2026-11-16

## Context

The generated pre-commit config called detect-secrets with `--baseline .secrets.baseline`, but the template shipped no such file. The hook exits with `argument --baseline: Invalid path: .secrets.baseline`, so every new project had to create a baseline by hand before its first commit.

A baseline is a list of known findings to ignore, plus the scanner settings. The options were:

1. ship a generated baseline in the template — it records line numbers and hashes of the rendered files, so it goes stale with every template change and differs per answer set;
2. tell users to generate one after `copier copy` — one more manual step, and it silently accepts whatever is in the tree at that moment;
3. run without a baseline.

Tested with detect-secrets 1.5.0 on freshly rendered projects: without a baseline the only findings are `.copier-answers.yml` (the answer line `secrets: <choice>` matches the keyword detector) and the commented example URL in `.env.example`. `uv.lock` is not flagged. A planted AWS key and a password assignment are caught.

## Decision

No `--baseline` argument. The hook excludes `.copier-answers.yml`, and the example line in `.env.example` carries `# pragma: allowlist secret`. Every other finding blocks the commit; a false positive is marked inline with the same pragma.

A project that outgrows inline pragmas (generated files, fixtures full of fake keys) opts into a baseline itself; the generated `quality-gates.md` says how.

## Consequences

- Hooks work on the first commit of a new project with no extra step.
- `just test-render` runs detect-secrets over every rendered project, so a template change that introduces a false positive fails the test.
- False positives are visible at the line that causes them instead of being hidden in a JSON file.
- A project that adds a baseline has to keep the `--baseline` argument through `copier update` merges of `.pre-commit-config.yaml`.
- Not verified here: the content of a baseline generated by `detect-secrets scan` for a fresh project.
